# ResuAlign 市场情报报告

**生成日期**: 2026-08-18
**分析框架**: Trend Researcher Product Agent

---

## 1. 市场细分与规模

**TAM（总潜在市场）**：全球 AI 求职工具市场，2025-2030 年 CAGR 25-35%。核心驱动力：AI 生成简历/定制化、ATS 优化、求职自动化。

**SAM（可服务市场）**：
- 中国校招/实习市场（2025 年预计 1200 万应届生 + 2000 万实习求职者）
- 技术岗位求职者（后端/前端/算法/数据 — 与 ResuAlign 现有分类吻合）
- 英语技术岗位（海外求职者用英文 JD，ResuAlign 已有双语支持）

**SOM（可获取份额）**：
- 个人自托管工具（非 SaaS）天花板较低，但用户粘性极高
- 目标：1-5k 活跃开发者/求职者，非大众市场，而是深度技术用户和效率追求者

## 2. 竞争格局

| 分类 | 代表产品 | ResuAlign 差异化 |
|------|----------|------------------|
| 中文简历工具 | 超级简历 WonderCV、职徒简历 | 不做排版/模板，做 AI 定制改写 |
| 英文 AI 简历 | Rezi、Kickresume、Enhancv | 全国产、自托管、无边界的本地数据 |
| 面试准备 | 牛客网、LeetCode | 不做刷题，做投递闭环管理 |
| 求职管理 | Huntr、Teal、Simplify | 本地 SQLite 不依赖第三方、Agent 定制 |
| 大模型应用 | 各种聊天包装 | 专业 Prompt 工程 + Provenance 锚定 |

**关键信号**：2025 年出现 AI 求职 Copilot 浪潮，但普遍是：
- **SaaS 订阅制**（每月 $20-50），用户数据在云端
- **通用型**（一个 Prompt 改所有简历），不针对岗位
- **无闭环管理**（只有改简历，没有投递 + 跟进）

ResuAlign 的 **自托管 + 岗位定制 + 投递闭环** 在这个光谱上几乎是空白。

## 4. 机会评估

### 核心机会
个人自托管求职工作台，把筛岗→定制→投递→跟进跑成一条闭环。

### 三个差异化支柱
- **Provenance 锚定** — 每句改写可溯源到原始简历，不捏造事实（竞品通常做不到）
- **角色化 Agent 架构** — 不是一个大 Prompt，而是专业分工的 Agent 团队
- **本地数据主权** — SQLite + 自托管，不出网（对应竞品 SaaS 的数据隐私风险）

### 威胁信号
- 竞品开始嵌入"岗位匹配分"功能（如 Simplify 的浏览器插件）——需要差异化算法
- 大模型自带长上下文（128K+），部分抵消了角色拆分的必要性——但本地模型仍需要
- 用户获取成本高：自托管工具依赖口碑/社区，而非投放

---

## 5. 战略建议

1. **差异化叙事**：不是"AI 简历生成器"，而是"个人求职工作台"——强调闭环管理而非单点功能
2. **社区先于产品**：自托管工具的用户获取来自 GitHub/技术社区，先完善 README 和 onboarding
3. **本地模型优先**：角色化拆分 + 135B 以下模型可运行，是自托管场景的核心卖点
4. **避免功能膨胀**：不做面试模拟、不做薪资谈判助手，专注筛岗→定制→投递→跟进闭环
