# ResuAlign 本地摄入油猴脚本安装说明

`resualign-collector.user.js` 是 ResuAlign V4 的客户端摄入器（ADR-0028）。
它提供两种摄入模式：

- Specific 模式：实习僧（shixiseng.com）岗位详情页右下角一键「摄入岗位」，
  按岗位 URL 查重。
- Universal 模式：任意网站划词选中 JD 后，右下角浮层出现「摄入选区 JD」，
  按 JD 文本哈希查重。

脚本不会自动弹出新标签页；摄入结果以右下角原地轻量状态显示（已入库 /
已在岗位库 / 失败原因），并可选「去工作台」链接。

## 安装

1. 浏览器安装 Tampermonkey（Chrome/Edge/Firefox）或 Greasemonkey。
2. 打开油猴管理面板 → 「新建脚本」。
3. 删除模板内容，把仓库根目录的 `resualign-collector.user.js` 全文粘贴进去，
   保存（Ctrl+S）。部分油猴版本也支持直接「从文件导入」该 `.user.js`。
   **保存/导入时如果弹出「是否允许此脚本连接到 127.0.0.1」之类的询问，务必
   选择允许**——经编辑器粘贴安装时该确认容易被跳过，后果见下文「域名授权」。
4. 打开任意页面，首次运行会弹出「ResuAlign 摄入配置」。

## 首次摄入前：浏览器权限（Edge/Chrome 用户必读）

**症状**：在招聘网站点「摄入」后，右下角没有任何反应，也不报错——请求被浏览器
拦在半路，而不是 ResuAlign 的问题。

**原因**：Edge 和较新版 Chrome 有一项叫「本地网络访问」的隐私保护：当一个公网
网站（例如腾讯招聘页面）试图把数据发往**你自己电脑上的程序**（ResuAlign 服务，
地址 `127.0.0.1`）时，浏览器会先拦下来问你一句。这一步必须人工允许一次。

**允许方法（首次弹出时）**：地址栏附近会出现提示
「某某网站 想要访问此设备上的其他应用和服务」→ 点击**允许**。

**错过了提示也没关系**（提示只出现一次，但权限可以手动补）：

1. 点击地址栏最左侧的站点信息图标（感叹号或滑块），选择「权限」/「网站权限」；
2. 找到「本地网络访问」或「访问此设备上的其他应用和服务」，改为**允许**；
3. 刷新岗位页面，重新点摄入。

**跨浏览器说明**：这个拦截是 Edge / Chrome 较新版本的特性；Firefox 不会出现该
提示，Firefox 用户摄入失败时请直接按文末「摄入首查三步」排查。

## 首次配置

1. 启动 ResuAlign 本地服务（默认 `http://127.0.0.1:8000`；端口被占用改用
   8001 等时，直接改这里即可）。
2. 打开工作台「系统设置」，找到「本地摄入 Token」区块，点击「复制」。
3. 回到配置框，粘贴 Token；服务地址默认预填
   `http://127.0.0.1:8000`，点击「保存」。
4. 配置会写入 `GM_setValue`，后续打开页面无需重复填写。

## 域名授权：为什么点了摄入「毫无反应」

脚本向本地服务发请求走的是 Tampermonkey 提供的网络通道，需要浏览器扩展单独
放行 `127.0.0.1` 这个目标地址。**这一步和上面的浏览器权限是两层独立的门，
缺一不可**——只允许了浏览器权限、没确认域授权，症状同样是：点摄入按钮后
右下角毫无反应、也不报错（请求在扩展层就被静默拦下，网络面板里都看不到）。

补授权方法（按顺序尝试）：

1. 点击浏览器右上角的 Tampermonkey 图标：若有「此脚本想要访问 127.0.0.1…」
   之类的待确认项，选择**允许 / 始终允许**。
2. 若看不到询问：打开油猴管理面板 → 本脚本「设置」→ 找到「已允许跨域
   访问的域名 / Universal allow」相关区域，确认 `127.0.0.1`（以及你改用的
   端口对应地址）在允许列表中。
3. 最省事的兜底：删除脚本重新安装，安装/保存过程中弹出的所有域名确认都
   点「允许」（经编辑器粘贴安装时这些弹窗最容易被错过）。

## 使用

### 通用岗位页智能提取（0.2.0 新增，推荐）

打开任意招聘网站的岗位详情页，脚本会自动识别页面（DOM 启发式 +
JSON-LD 结构化数据，纯本地运行、零 LLM 调用）；识别成功时右下角浮层
出现「一键提取岗位」按钮：

1. 点击按钮，脚本自动展开折叠的 JD 正文（「展开全文/查看更多」）、
   触发懒加载，然后提取标题 / 公司 / 地点 / 薪资 / JD 正文入库。
2. SPA 站点内切换岗位时自动重新识别，无需刷新。
3. 识别不出时不显示按钮——此时请退回「通用划词」方式。

### 实习僧岗位详情

打开 shixiseng.com 的岗位详情页，右下角会出现「摄入岗位」按钮。脚本会提取
标题、公司、地点、薪资和 JD 正文，以 `classification_pending=1` 秒级入库。

### 通用划词

1. 在任意招聘官网页面选中 JD 正文（至少 20 个字符）。
2. 右下角浮层出现「摄入选区 JD」。
3. 点击后发送 `document.title` + 当前 URL + 选中文本。

## 反馈与故障排查

- 已入库：新岗位写入成功。
- 已在岗位库：命中查重，不会覆盖已有岗位的 status / notes / final_draft。
- 摄入失败：请求字段或服务端校验失败，原因显示在浮层。
- 401 / Token 无效或已重置：脚本会清空本地 Token 并重新弹出配置框，请到
  系统设置页复制新 Token。重置后旧 Token 立即失效。
- 连接失败：确认 ResuAlign 服务已启动，且「服务地址」端口与启动端口一致。
- 点摄入后**毫无反应、也不报错**：这是最常见的「静默卡死」，几乎总是下面
  两步权限没做——按「摄入首查三步」排查。

### 摄入首查三步

按顺序查，每步都有可独立验证的判据：

1. **服务在跑吗？** 新开标签页访问 `http://127.0.0.1:8000/health`（端口以你
   实际启动为准），能看到一段 JSON 状态即服务正常。看不到 → 先启动 ResuAlign
   本地服务。
2. **浏览器允许「本地网络访问」了吗？** 在岗位页地址栏左侧的站点信息图标 →
   权限 → 「本地网络访问」应为**允许**（Edge/Chrome 专有，见上文专节）。
3. **Tampermonkey 的 127.0.0.1 域授权了吗？** 点 Tampermonkey 图标或进脚本
   设置检查（见「域名授权」专节）。

三步全过仍然无反应：把右下角浮层的最后一条状态截图 + 上面第 1 步 health 页
截图一起反馈，便于定位。

## 安全说明

Local Ingest Token 是本地工作台的访问凭据，不要粘贴到公开网页或分享给他人。
该 Token 只在 `X-ResuAlign-Token` 请求头中发送到你配置的服务地址；油猴脚本
不会自动打开任何新标签页。
