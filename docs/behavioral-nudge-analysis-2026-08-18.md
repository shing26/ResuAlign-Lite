# ResuAlign 行为交互诊断与闭环方案

**生成日期**: 2026-08-18
**分析框架**: Behavioral Nudge Engine Product Agent

---

## Phase 1: 当前交互逻辑诊断

### 发现 1: 功能分散，缺乏统一入口

**现状**：用户进入首页看到岗位库、工作台、简历中心、设置页、仪表盘五个平级入口。

**问题**：求职是一个**时序流程**（收到 JD → 分析匹配 → 定制简历 → 记录投递 → 跟进面试），但 UI 没有引导用户走这个流程。用户需要自己决定"下一步做什么"，认知负荷过高。

**认知负荷分析**：每多一个平级导航选项，用户决策时间增加 1-2 秒。5 个平级选项 → 用户可能不做任何操作就离开。

### 发现 2: 工作台的"单次对齐"缺乏状态持久化

**现状**：工作台打开一个岗位 → 看到 JD 分析 → 选择简历 → 点击对齐 → 等待结果 → 看到 diff → 采纳 → 导出。如果用户中途关闭页面，状态丢失，需要从头开始。

**行为心理学**：Zeigarnik 效应——未完成的任务比已完成的任务更容易被记住。但前提是用户能预期这个任务在合理时间内完成。如果用户预期要等 30 秒到 3 分钟（LLM 调用），他们不太可能在中间打断后回来。

### 发现 3: 投递后没有"下一步"引导

**现状**：用户标记"已投递"后，状态迁移记录的终点是"已投递 → 面试中 → 已拿 Offer/放弃"。但用户投递后最大的心理缺口是"然后呢？"——什么时候跟进？用什么方式？有没有收到回复？

**行为心理学**：进度效应（Progress Effect）——用户看到进度条时，完成最后一小段的动力远大于从零开始。但投递后的状态是"已投递"，没有进一步的进度信号，用户容易停滞。

### 发现 4: 缺少"赢"的反馈

**现状**：用户完成全部流程（分析 → 定制 → 投递 → 拿到 Offer）后，系统没有仪式感反馈。没有"恭喜！你完成了整个求职闭环"的庆祝，也没有回顾数据。

**行为心理学**：完成效应（Completion Effect）——当任务完成时获得正向反馈，用户更愿意继续使用。缺少反馈 = 用户觉得"这个工具对我没有帮助"。

## Phase 2: 业务逻辑闭环修复

### 修复 1: 时序引导（Temporal Scaffolding）

把首页改为"今日待办"视图，按求职时序引导：

```
┌──────────────────────────────────┐
│  ✅ 今日待办（3 项）              │
│                                  │
│  1. 新岗位待分析：后端开发（深圳）  │
│     [分析匹配] → 8 分钟           │
│                                  │
│  2. 待跟进：字节跳动 - 一面       │
│     [写跟进] → 2 分钟             │
│                                  │
│  3. 待投递：阿里巴巴 - 已定制完成  │
│     [去投递] → 5 分钟             │
│                                  │
│  🎯 本周进度：投递 3 家 / 面试 1 家 │
└──────────────────────────────────┘
```

**原则**：每次只展示 1 个最重要动作，而不是"你有 50 个待办"。

### 修复 2: 工作台持久化 + 微型 Sprint

- 工作台状态持久化（当前已部分实现，session 有 TTL 30 分钟）
- 加入微型 Sprint：向用户展示"只需 5 分钟就能完成对齐"
- 进度条：对齐进度可视化

### 修复 3: 投递后 Nudge 序列

| 时间 | 触发 | 内容 |
|------|------|------|
| 投递后 0 天 | 自动 | "恭喜投递！已记录。建议设置跟进时间→" |
| 投递后 3 天 | 无状态变化 | "投递 ${公司} 已 3 天，还没有收到回复？试试 [准备跟进消息]" |
| 投递后 7 天 | 无状态变化 | "一周了，也许可以换个方式：看看岗位还有没有类似机会？" |
| 面试后 0 天 | 状态 = 面试中 | "面试辛苦了！记得记录面试反馈，[写面经]" |
| 面试后 3 天 | 无状态变化 | "面试后三天了，可以发一封感谢信/跟进邮件" |

### 修复 4: 完成仪式

- 当用户标记"已拿 Offer"时，触发庆祝 + 数据回顾
- 展示："你改了 ${n} 次简历，投递了 ${m} 家，面试了 ${k} 次，最终拿到了 Offer 🎉"
- 导出"求职报告"PDF（含时间线、投递漏斗、面试记录）

## Phase 3: 助推设计（Nudge Architecture）

### 每日首次打开
```
早安！你有 3 个待跟进的岗位。
今天花 5 分钟就能完成所有跟进。
要不要从 [字节跳动-自由跟进] 开始？
```

### 长时间未使用
```
你已经 3 天没有打开工作台了。
你收藏了 5 个新岗位，要不要花 10 分钟看看？
(如果不需要，也可以设置静默一周)
```

### 完成 Sprint 后的庆祝
```
Nice work！你完成了 3 次跟进，整理了 2 份简历。
今天还要继续吗？
[再做 5 分钟]  [今天先到这里]
```
