# 0046 — `style=` 内联自定义属性白名单（阻断 `@layer` 覆盖不到的旁路）

Status: accepted (2026-09-18 用户逐项裁定；施工待 ADR-0042 冻结令解冻)

## 背景（证据链，非估计）

1. **`@layer` 无法覆盖内联样式**。内联声明不属于任何 layer，永远赢过所有层。
   因此分层只解决了「层间覆盖」，内联样式是它够不到的旁路。
2. **旁路一：模板内联视觉属性。** 35 处模板 `style="..."` 带视觉属性
   （`color` / `padding` / `border-radius` 之类），绕过整个设计系统。
3. **旁路二：运行时注入的自定义属性。**
   `format.js:1863-1864` 在庆祝动效里注入 `--d` / `--x` / `--delay` / `--c`，
   而 CSS 侧（`styles.css:1412-1419`）**无 fallback**——JS 一旦抛异常，
   整条 `animation` 声明失效。
4. **一处必须留档的复核更正。** 本 ADR 初稿曾据「`--stagger-index` /
   `--diff-index` 疑似从未注入」主张清理这两条延迟声明。
   **该前提已被复核证伪并撤回**：二者由 CSS `:nth-child()` 规则在
   `styles.css:3312-3330` 与 `3353-3376` 侧直接赋值，赋值宿主与消费点
   （`styles.css:3309` / `3350`）是同一元素，**机制正常生效**。
   复核方法上的教训：只 grep JS 侧注入（0 命中）就下「从未注入」的结论，
   漏掉了 CSS 侧 `:nth-child()` 这种赋值方式。
   **本条不得作为施工动作。** `format.js:739` 的 `data-diff-index`
   只是冗余属性，不参与计算，保留不动。

## 决定

**1. 内联 `style` 只准放数据驱动的数值型自定义属性；不准放视觉属性。**
`color` / `background` / `padding` / `margin` / `border-radius` / `font-*` /
`width` / `height` 等一律移入 CSS 类。

**2. 建立内联变量白名单。** 只有下列变量允许由 JS 注入：

| 变量 | 注入方 | 类型 | 说明 |
|---|---|---|---|
| `--ra-i` | 列表渲染 | `<integer>` | 列表项序号（用于 `nth-child` 之外的错峰） |
| `--ra-score` | 分数环（若启用） | 0–100 | 分数百分比 |
| `--ra-confetti-*` | 庆祝动效 | `<length>` / `<color>` | confetti 专用，前缀隔离 |

**3. CSS 侧必须给所有白名单变量提供 fallback。**
例如 `var(--ra-score, 0)`。理由：保证 JS 异常时声明仍然有效。

**4. CI 校验。** `grep -oE 'style="[^"]*"' app/*.js` 的结果中，`--` 开头的
自定义属性必须全部命中白名单；出现任何视觉属性 → 验收失败。

**5. 禁止把 `data-*` 属性当自定义属性消费。** 如需用 `data-*` 驱动样式，
用属性选择器 `[data-x="..."]`，不用 `var(--data-x)` 形态。

> **本 ADR 不含「删除 `styles.css:3309` / `3350` 的延迟声明」这一动作。**
> 该动作属于被撤回的初稿结论，见背景第 4 条。

## 后果

**正面**

- 堵住 `@layer` 唯一够不到的旁路；设计系统不再有绕过通道。
- confetti 的 4 个注入变量获得 fallback，JS 异常时不再整条 `animation` 失效。

**负面 / 代价**

- 把 35 处内联视觉属性搬进 CSS 类**需要改 JS 模板**，受 ADR-0042 冻结约束，
  须解冻后执行。
- 白名单机制给「新增一个动态变量」增加了流程成本（有意为之，用于防止
  内联变量无序扩张）。
- 白名单变量使用组件私有注入前缀，与 ADR-0044 的全局 token 命名分域。
  这是**有意的**：便于 CI 区分「谁允许注入」。施工时若改用全局命名形态，
  须同步改本条与 CI 规则。

## 与既有 ADR 的关系

- **ADR-0043**：本 ADR 补其「不能对抗内联样式」的边界。
- **ADR-0044**：内联变量最终仍需落到 token 取值。
- **ADR-0047**：`--paper-*` 语义不受本条影响。
