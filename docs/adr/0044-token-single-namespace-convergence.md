# 0044 — Token 收敛为单一命名空间，深色为默认设计面

Status: accepted (2026-09-18 用户逐项裁定；施工待 ADR-0042 冻结令解冻)

## 背景（证据链，非估计）

1. **四套命名体系并存**。`styles.css` 实测 10 个 `:root` 块、552 条变量声明、
   242 个唯一变量名，其中 **157 个被重复定义**（`--surface-panel` 定义 6 次，
   19 个名字各定义 5 次）。四套体系：legacy（`--bg`/`--surface`/`--text`）、
   apple（`--apple-*`）、v3 shell（`--bg-canvas`/`--surface-panel`/`--ink`）、
   `--ra-*`。
2. **引用但未定义的变量（逐条复核后的真实数量）**。简报初稿称 25 个「一律
   静默失效」，复核后分类为：真失效 1 条（`--score`，落在死选择器 `.score-ring` 上）、
   **软失效 9 条**（有硬编码字面量 fallback，主题切换时永远显示固定色，这才是
   「怎么调都不对」的直接元凶）、类作用域合法 12 条、JS 运行时注入 4 条、
   审计误报 1 条（`--card-*` 实际定义在 `styles.css:160-180`）。
   **跨 15 个前端文件独立复扫的结果：真正「从未定义」的是 10 个**
   （`--ra-accent` `--ra-surface` `--ra-surface-soft` `--ra-surface-soft-hover`
   `--ra-text-muted` `--ra-warn` `--accent-deep` `--warning-deep` `--score`
   `--match-soft`）。数字必须按 10 引用，不按 25。
3. **硬编码颜色**。十六进制字面量 508 处 / 157 色值；`rgb()/rgba()` 299 处 / 169 值。
   其中「主色」这一个概念有 3 个候选同时出现（Tailwind blue `#2563eb` ×13、
   Apple blue `#007aff` ×8、indigo `#4f46e5`/`#6366f1` ×12），另有第 4 个蓝
   藏在 `--card-shadow-selected` 的 `rgba(22,86,232,.22)`。
4. **尺度失控**。`font-size` 339 处 / 63 个不同取值（`12px` ×55 与
   `var(--text-12)` ×32 并存）；间距非 token 字面量 1175 处；`border-radius`
   259 处 / 40 个取值 / 8 套命名；`box-shadow` 130 处 / 70 个取值 / 10 套命名；
   `z-index` 17 处 / 12 个散值无刻度；固定 px 高度 164 处，按钮高度
   36/38/40/44 四档并存。
5. **字体现状**。`styles.css` 无 `@font-face`（0 处），`static/` 目录零二进制
   资产；`--font-ui`（`:root#1`）、`--apple-font`（`:root#7`）、`--ra-font-ui`
   三套并存竞争。数字等宽对齐已由 `font-variant-numeric: tabular-nums`
   （23 处）承担，不依赖等宽字体。

## 决定

**1. 唯一 canonical token 源 = 设计侧交付的 `design-tokens.css` 内容，形态为
内联进 `styles.css` 的 `@layer tokens` 顶部**（承载方式见 ADR-0043 决定 6）。

**2. 命名基准 = 无前缀语义名。** 采用交付物现有形态：
`--bg-canvas` / `--surface-1` / `--text-primary` / `--accent` / `--space-1` /
`--radius-md` / `--z-modal` / `--control-h-md` / `--ic-sm`。

> 本节明确撤回架构方案初稿「必须带 `--ra-` 前缀」的要求。撤回理由：前缀不构成
> 可验证约束（治理度的真实指标是「业务代码里 0 处色值字面量」，与前缀无关），
> 而代价是给约 200 个 token 做一次零功能收益的改名。

**3. `--ra-*` 降级为迁移别名，不构成第二命名空间。** 只允许存在于一个
**默认不生效**的别名块（选择器 `:root:where([data-ra-alias])`），供存量
`styles.css` 里的 `--ra-*` 引用做机械比对。新代码禁止引用 `--ra-*`。
**默认不生效是刻意设计**：不许 `--ra-*` 与新命名同时作为全局命名空间存在，
否则「第五代 token 体系」当场成立。

**4. `--paper-*` 保留原名，不参与命名收敛。** 它属于「文档纸张」语义域，
与 UI chrome 是两个域；A4 预览 / 打印 / 导出恒为白纸黑字，
`[data-theme="light"]` 中禁止重声明。约束：只允许在打印 / 文档预览相关规则
中被引用，不得扩散到 app shell。

**5. 深色为默认设计面，浅色为次级可切换主题。** 主题值由 ADR-0047 裁定。

**6. 唯一强调色 = 冷青 `#1FA8BC`（hue ≈ 190）**，`--info` 保留蓝色
（`#4E9BF0`）并与之明确分工。全系统零渐变：不提供任何 gradient token。

**7. 数值语义与状态语义分离（本项目专属扩展）。**

- **序数色阶 `--ord-1..5`**（0–39 / 40–59 / 60–74 / 75–84 / 85–100）+
  `--ord-track`，统一服务所有 0–100 连续数值：匹配分、ATS 分、技能覆盖率、
  对齐完成度、四维匹配分。渲染语法固定两种：meter 填充 / 数值文字着色，
  **禁止作为徽标实底**。
- **状态色**（`--success` / `--warn` / `--danger` / `--info`，各带 `-soft` / `-line`）
  只渲染为三种语法：6px 圆点 / 1px 描边徽标 / 细边框着色，
  **禁止用于 meter 填充**。
- 两者**不共用 token**。`--ord-5` 与 `--success` 在深色下取值相同是有意保留
  （「优秀」与「成功」本就该同色），靠 token 分离与渲染语法分离避免语义打架。

**8. canonical 源结构 = `@layer tokens` 内深色 1 块 + 浅色 1 块；每个全局
token 名全文件只定义 1 次。** 浅色块只重声明「必须换值」的 token
（底阶 / 描边 / 前景 / 强调色 / 状态色 / 序数色 / 遮罩 / 阴影 / data-URI 图形），
不重声明间距 / 圆角 / 字号 / 行高 / 动效 / 层级 / 控件高 / 图标尺寸 / 栅格 /
`--paper-*`。

**9. 刻度收敛。**

| 维度 | 现状 | 终态 |
|---|---|---|
| 字号 | 63 个取值 | **8 档**（`--text-2xs..3xl`，11/12/13/14/16/18/20/24px，rem） |
| 间距 | 1175 个非 token 字面量 | **4px 基准网格 11 档**（`--space-1..16`，索引≠像素值）；禁 5/7/9/11/13/15/22/30px |
| 圆角 | 40 个取值 / 12 套命名 | **7 档**（`--radius-xs/sm/md/lg/xl/2xl/pill`）；卡片上限 12px，禁 ≥24px |
| 阴影 | 70 个取值 / 10 套命名 | **4 档 + `none`**（popover / modal / toast / drag）；**卡片/面板/按钮/输入框/表头一律 `none`** |
| z-index | 12 个散值 | **9 档语义命名**（`--z-below..toast`） |
| 控件高 | 36/38/40/44 四档 | **4 档**（24/28/32/36）；44px 降级为 `--hit-min` 触摸命中区 |
| 图标尺寸 | 无刻度 | **3 档 + 1 受限**（16/20/24，例外 12 仅 meter 与徽标内） |

归位规则：连续刻度（字号 / 间距 / z-index）取数值就近，等距时取小档；
决策刻度（圆角逐元素语义 / 阴影 / 控件高 / 图标尺寸）按交互语义归位，数值只作参考。

**10. 侧栏与顶栏尺寸。**

- `--rail-w: 224px`（4px 网格倍数，内容区最宽，与已评审样张一致）。
  实测录音：现状生效值 **230px**，而 `alignment-gap.test.mjs:121` 断言的
  **240px 命中的是一条被覆盖的定义**（`styles.css:7298`），v3.1 层
  `styles.css:11096` 的 `230px` 才是生效值。因此「基线绿优先」不构成选 240 的理由。
  该断言须重写为「必须引用 `--rail-w`」。
- `--topbar-h: 52px`。实测现状 **64px**。同一条测试的
  `.topbar{height:64px}` 断言同样须重写为「必须引用 `--topbar-h`」。

**11. 字体 = Inter Variable（拉丁 UI）+ JetBrains Mono（数字/等宽），均自托管。**

- 交付形态：`src/resualign/static/fonts/` 放自托管 woff2 文件 + OFL 许可文件，
  并在 `@layer tokens` 补 `@font-face`。**这是 `static/` 目录第一次引入二进制
  资产**，属已批准的依赖。
- 栈：`--font-ui` 以 Inter Variable 起头（后接 CJK 系统栈），
  `--font-mono` / `--font-num` 以 JetBrains Mono 起头。
- 禁止引用远程字体 CDN（本产品本地运行、数据不出本地，离线时字体回退不可控）。
- `font-display` 取值与许可文件落点在施工单中细化，不阻塞本 ADR。
- 数字对齐仍需 `font-variant-numeric: tabular-nums`（现有 23 处），
  字体本身不替代该属性。

**12. 软失效 9 条的修复目标名一律改写为 canonical 无前缀名，并补齐缺失定义。**
即：`--ra-accent` → 定义 `--accent` 并删除 4 处 `var(--ra-accent, #6366f1)`
硬编码 fallback；`--ra-surface` / `--ra-surface-soft` / `--ra-surface-soft-hover` /
`--ra-text-muted` / `--ra-warn` → 改为引用对应全局 token 并删 fallback；
`--match-soft` → **定义 `--match-soft`**（当前交付物只有 `--ord-*` 与
`--ra-match-*` 别名，缺这一条落点）；`--accent-deep` / `--warning-deep` → 废弃并直引全局 token。

## 后果

**正面**

- 主题切换真正生效（9 处软失效 fallback 全部移除）；`--accent` 定义后 indigo
  不再靠硬编码 fallback 兜底。
- 「单一强调色」这一目标第一次有结构性保障：4 个蓝收敛为 1 个青 + 1 个 info 蓝。
- 组件私有 token 有独立命名空间（`--<component>-*`，只在该组件块定义消费），
  「第五代 token 体系」在命名规则上无处安放。
- 间距阶梯落回 4px 网格后，验收项「间距必须为 4px 整数倍」成为机器可判定。

**负面 / 代价**

- 157 个重复名按「最后生效值」收敛需要一次性求解脚本（复用
  `ux-regression.test.mjs:61-83` 的特异性解析逻辑），约 0.5 人日。
- 控件高度归位是语义决策而非算术，必须逐组件确认。
- 间距放弃 2/6/10px 微步：实测高频值 `6px` ×119 与 `10px` ×192 将分别归到
  8px 与 12px，**垂直留白会略增**，与「高密度」方向存在张力。若迁移后样张
  显示密度不足，在 token 层加微步（改一处定义，不改调用点）。
- 深色成为默认后，浅色主题的回归覆盖度天然下降 → 施工须把「明暗双主题截图」
  列为强制项，否则浅色会静默腐化。

## 与既有 ADR 的关系

- **ADR-0033**：其决策 1（Slate + Indigo / 默认浅色）由 ADR-0047 取代；
  其决策 5（投递快照右侧抽屉）、决策 7（全站唯一「投递快照」术语）、
  决策 9（emoji → 16px 线性 SVG）**保留有效**。
- **ADR-0043**：提供 `@layer tokens` 这一承载层与层序保障。
- **ADR-0045**：图标尺寸 token 与本 ADR 的三档对齐。
- **ADR-0026 / ADR-0031**：其视觉结论不改，本 ADR 只统一承载它们的 token。
