# 0038 — 主叙事维持工具化工作台；agent 以 Pro 旗舰能力入场，不等 Aha 验证

Status: accepted (2026-09-14)

> 2026-09-15 注记（ADR-0041）：叙事位不变，排期冻结——Phase A/B 与
> 商业化 PRD 一并挂起，需求线 (a) 合格例仍为 0；恢复条件见 ADR-0041
> 决定 9（探针过）/决定 10（证伪归档条款）。

ResuAlign agent 化与商业化 PRD（`docs/prd-commercialization-20260905.md`，Draft）正面相撞：(a) 工具化工作台叙事（¥39/月，Aha = 首次采纳 ≥3 张溯源卡并保存终稿，按钮流），agent 是第二引擎；(b) 卖点改为「会自己动手的 AI 求职助理」，agent 直接进主线。两条都成立，混着走最危险；而 (a) 的字面执行（"Aha 验证做完再上 agent"）有死结——产品尚未上线，验证做完永远不会发生。

**决定：主叙事维持 (a)——PRD 一句话定位、Aha 定义、落地页文案零改动；但 agent 不进观望区：定位为 Pro「省事」价值档的旗舰能力**（付费场景 S6，PRD §3.2/§4.1 补两行，见下）。Phase B（指挥台 UI 露出）的触发条件 = **上线后首批激活率数据回正，或 Phase A 完成后 4 周，二者先到**；在那之前 agent 只存在于终端与 API。§2「不做自动海投」红线不动：agent 只对用户已录入的岗位做对齐，永不代投。

## Why

Aha 击中的三痛点是「差距在这 / 只要一分钟 / 它没有编造」。指挥台直接强化"一分钟"（省时省力），但对"没编造"信任叙事是纯风险——自主 agent 动简历正是用户头号恐惧，审批档只能兜底不能加成。所以主叙事不给它，Pro 价值档给它：省时恰是付费升级动机（留存/转化位），不是首次激活位。

## Consequences

- Phase 0 / Phase A 立即开工，不被上线阻塞（两者不碰叙事、不改现有行为）。
- PRD 追加（2026-09-14）：§3.2 新增 S6 软墙场景；§4.1 新增指挥台版本行。其余零改动。
- 决策协议若被 ADR-0037 实测拍成「模板化编排」，S6 文案按能力实际收敛改写——叙事承诺不得超出测出的协议。
