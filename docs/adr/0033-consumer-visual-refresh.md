# ADR-0033: 消费者视觉刷新（Consumer Visual Refresh）

**状态**: 已接受
**日期**: 2026-08-21

---

## 背景

V3 shell（ADR-0026）与文档润色范式（ADR-0031）解决了产品心智模型，但视觉仍偏向开发者语境：深色默认、230px 深色 rail、代码 diff 式三栏工作台。用户要求先出可视设计稿（`design-preview.html`，纯静态未改代码）再拍板；经三轮确认（Q1–Q6 + 改动清单 A–E 全部确认），本轮为**消费者取向视觉刷新**。

## 决策

**范围 = 视觉层 + 少量纯前端交互，不碰任何 API / 后端 / 数据模型。** 具体：

1. **设计系统**：Slate + Indigo 配色，`--primary: #4F46E5`。**默认浅色**，保留明暗 toggle；暗色主题下 A4 简历纸保持白底（纸的语义），仅外壳切换深色。
2. **侧栏**：6 路由全保留；footer 升级为「今日云端额度 + 进度条」（数据与系统设置成本护栏**同一数据源**，消除预览期 ¥2.36 vs ¥0.42 的不一致）；「个人模式」只作为部署状态显示在 footer，不再出现在顶栏。
3. **工作台**：A4 简历纸（210×297 视觉、纸面白底）+ 右栏四 tab「建议 / 岗位分析 / 面试记录 / 优化设置」；顶部「对照编辑 ↔ A4 预览」双模式开关——A4 是结果视图，对照编辑保留现有 diff 画布过程视图。**Live Sheet（定稿实时预览）必须保留**，作为「面试记录」tab（现有 renderLiveSheetHtml 纯函数 + 增量高亮复用）。
4. **建议卡**：保留「高可信 / 建议复核」provenance pill（有真实数据），**删除 per-card "+12分/+6分"**（数据模型无 per-diff 分数）；提分只体现在头部匹配度（rerun 后真实变化）。
5. **快照**：投递快照用**右侧抽屉**（自 ADR-0028 的模态升级而来）；「固化投递快照」不设独立按钮——快照是「记录投递」的原子产物（词表既有约束），入口收敛到已投递行 / 工作台抽屉。
6. **顶栏收敛**：删除全局「快速导入 JD」按钮（导入放岗位库 + Ctrl+K）、全局岗位下拉（工作台才有岗位作用域）、顶栏「个人模式」绿点；保留命令栏（Ctrl+K）与明暗 toggle。万一用户从导航找不到快速导入的入口，回退方案是把按钮放回岗位库工具栏（已落实：岗位库工具栏本来就有「添加岗位」）。
7. **术语统一（词表）**：UI 全站「投递快照」唯一叫法（避免「对齐快照 / 记录快照」自造词）；「已对齐」= alignment_status==="succeeded"（现有代码语义，format.js）不作新含义；「对齐」只指对齐过程。
8. **不实现**：设计稿 View4 的「角色-模型绑定（Profiler/Gap/Editor/Evaluator）」（现有接口是单激活节点 + 备用节点，ADR-0030 与实际部署不符，按不新增功能原则如实映射为 LLM 节点卡）。
9. **emoji → 16px SVG 线性图标**（12 处 D3 清单）+ badge-pill 徽标；组件动效（paneIn / fadeInHighlight / acceptFlash）沿用 ADR-0017/0026 的 prefers-reduced-motion 门控体系。

## 为什么现在做

- 目标用户是求职者（非开发者），A4「所见即所得」的纸面隐喻比 diff 分栏更可信；表达「我改了什么」用对照模式，表达「最终投出去的样子」用 A4。
- 纯视觉窗口期：接口契约（data-* / aria-* / 路由 / 表单）保持不变，改动集中在模板字符串与样式层，风险可被 400+ 前端断言覆盖。

## 后果

- `styles.css?v=28` 与 `main.js?v=28` 需 bump（静态缓存）；`index.html` 移除硬编码 `class="dark"`，默认浅色由 `:root` 决定。
- tests/frontend 直接子串断言（live-sheet / format / split-canvas）需同步更新（emoji→SVG、文案统一、按钮移除）。
- 本轮不改后端；成本护栏数据读取沿用现有设置页通道（`/api/settings` 或等价前端状态），footer 额度条是纯展示复用。

## Considered Options

- **全量重写 styles.css**：风险过高（11130 行含 Tailwind 工具类与 6846 行 Apple 覆盖层），放弃；改为在文件顶部/新增区块做 token 重映射 + 定向覆盖，保留既有类名。
- **A4 替代 diff 画布**：会丢「过程」视图，用户明确要两个都要 → 双模式开关。
- **建议卡保留分数**：无数据支撑会被用户戳穿 → 删除，只保留 provenance pill。
