# ResuAlign 用户指南

## 概览

ResuAlign 是一个本地求职工作台，围绕四个模块组织：

- 简历中心：长期维护一份或多份主简历，每个修改都成为一个可回滚的版本；
  每份简历都可独立发起诊断并查看评分、技能、问题与优化建议。
- 岗位库：保存岗位 JD、公司、城市、薪资、分类与投递状态；JD 链接解析失败
  时可一键改用粘贴，分类失败时保留「分类待定」并可稍后重试。
- 工作台：把一份主简历和一个岗位放在一起，做差距分析、AI 改写、Diff 采纳
  、定稿保存与投递价值评估。
- 设置：调整评估权重、薪资参照和分类词表；分类词表保存后立即同步到岗位库。

## 1. 简历中心

1. 打开页面后点击「新建主简历」，填写标题和 Markdown 内容并保存。
2. 卡片显示当前版本号和内容摘要；点击「版本历史」可查看每个版本与上一版的
   逐行 Diff，并可以把历史版本一键回滚为当前版本。
3. 编辑会追加新版本，不会覆盖旧版本；删除前需要二次确认。
4. 打开档案页后点击「诊断简历」，页面会显示阶段进度；诊断完成后展示
   0-100 分、技能、问题与优化建议，可重新诊断或导出 PDF / Markdown。
5. 诊断结果会记录最近一次任务，刷新档案页后可恢复查看。

## 2. 岗位库

1. 「添加岗位」支持粘贴 JD 或填 JD 链接；链接由内置爬虫抓取并清理正文。
   解析成功会预填标题、公司、城市、JD 文本与薪资区间，JD 文本仍可编辑。
   解析失败会显示原因与「改用粘贴 JD」按钮，点击后保留原 URL 作为来源链接。
2. 批量导入支持 CSV（`title,jd_text,company,location,...`）或 JSON 数组，
   导入在后台运行，页面会显示处理进度。
3. 每张岗位卡片都可展开「原始 JD」；「编辑」可修改分类、标签、薪资和状态。
   分类 LLM 失败时岗位仍会保存，卡片显示「分类待定」，点击「重新分类」可重试。
4. 顶部筛选器支持职能、级别、状态和关键词，列表分页展示。

## 3. 工作台

1. 从岗位库点击「打开工作台」，或直接访问 `#/workspace/:jobId` 深链。
2. 选择主简历、改写颗粒度（微调/重构/重塑）与 Prompt 聚焦策略后运行。
3. 运行期间显示阶段化进度（排队、诊断、JD 画像、差距分析、改写、评估）；
   排队中的任务可以取消，结束后可以重跑。
4. 结果页展示诊断分、优化后内容与逐条 Diff；勾选后点击「采纳选中修改」生成
   草稿，并可保存为该岗位的定稿。
5. 保存定稿后显示保存时间与版本号；刷新或重新打开工作台会自动恢复定稿。
   再次保存会覆盖为新版本，「另存为新主简历」会二次确认并创建新主简历，
   不会改动当前主简历。
6. 投递价值评估综合匹配度、薪资、硬性条件和岗位质量给出
   「投递 / 考虑 / 放弃」结论，并在薪资分下方标注基准来源（设置表 / 库内
   同类中位 / 暂无基准）与城市归一化结果。
7. 右侧可维护岗位状态和投递记录；更新投递状态不会影响已生成的工作台结果。

## 4. 设置

- 评估权重：四项权重合计必须为 100，保存后影响所有评估。
- 薪资参照表：按职能和城市维护 P50/P75 月薪，用于薪资得分基准。
- 分类词表：岗位职能、级别、状态的选项列表，每行一个。
  保存后岗位库筛选下拉与编辑弹窗立即使用新词表；接口不可用时回退内置词表。

## 数据与故障

- 所有数据在 `data/jobs.db`；备份/重置命令见 README。
- 队列任务在服务重启后会自动恢复并继续运行。
- 爬虫只允许 http/https，并拒绝内网/环回地址；下载有 5MB 上限和重定向上限。
- 默认是个人模式：打开首页直接进入简历中心，不出现登录表单；即使 API 返回
  401，页面也只显示可理解的错误，不会弹出登录框。
