# ResuAlign-Lite 项目状态解析

## 一、项目是什么

**ResuAlign 求职工作台**（`pyproject.toml` 版本 1.0.0）——一个**个人自托管求职工具**，把「筛岗 → 定制 → 投递 → 跟进」跑成一条闭环。核心是 LLM 驱动的简历-岗位对齐流水线（诊断 → JD 画像 → 差距分析 → 定制改写 → 评估），铁律是**不捏造事实**（每个改写必须溯源到主简历）。

技术栈：
- **后端**：Python 3.10+ / FastAPI / uvicorn / SQLite（`data/jobs.db`），约 45 个模块，含 agent 编排（MCP）、爬虫（boss直聘/实习僧等 Site Handler）、规则诊断、成本护栏
- **前端**：no-build 原生 JS（`index.html` + `styles.css` 259KB + `app.js` 等 13 个模块），无打包器
- **LLM**：deepseek（当前 `.env` 配置为 **deepseek-v4-flash**），另支持 openrouter/ollama
- **部署**：本地一键启动（`start.ps1`）+ 可选 Docker 双通道
