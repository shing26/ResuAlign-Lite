## 4. 黄金核心打磨（三项落地）

### 核心 1「改」：Bullet 级 STAR 动词重写
- **后端**：`BULLET_REWRITE_PROMPT` v2→v3，新增 **Few-Shot 强动词库**（构建/设计/落地/优化…），
  禁止弱动词（负责/参与/协助/了解/熟悉），强制「强动词 + 具象机制 + 量化插槽」三件套
- **前端**：新增「✏️ 编辑」按钮 → textarea 原地编辑 → 采纳时读取编辑后文本落稿（补全量化数字就地生效）
- 既有的「AI 润色」按钮（调用 rewrite 路由）保留，三入口齐备

### 核心 2「审」：高保真 A4 纸面与单页打印
- A4 预览统一 **10.5pt 标准中文字阶 + 1.5 行高**（原 1.62）
- `@media print`：**4px 项目间距**、标题字号分级（16/12/11pt）、`break-inside: avoid`
- **单页收敛**：`printTarget` 按内容长度自动加 `print-compact/--tight/--ultra` 三档压缩
  （9-10pt、1.3-1.42 行高、1-3px 间距），任何档位禁止额外分页，杜绝空白第二页

### 核心 3「投」：投递快照 + 面试防深挖 CheatSheet
- 既有能力验证完整：记录投递 → 原子写入 `application_snapshots`（append-only 版本化）+ 快照抽屉
- **面试防深挖清单**（`interviewCheatSheetHtml`）：从 JD 画像/差距报告/高置信 diff 确定性提炼
  「高频追问 + 两句话应答 SOP」，无新增经历事实，含幻觉复核告警
